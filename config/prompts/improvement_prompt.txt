Review a trading prompt using the supplied backtests. The objective is robust
risk-adjusted returns after costs, not maximizing a single backtest metric.

Separate decision errors from execution effects, regime exposure, and luck.
Account for sample size, correlated trades, selection bias, and missing cost or
benchmark information. One profitable period or a missed winner does not establish
an edge. Treat in-sample results as hypotheses that need independent, later-period
evaluation; do not claim a proposed change has already improved performance.

Make the smallest evidence-supported revision. Preserve effective guidance and
the trading prompt's JSON schema. Prefer concise decision criteria over indicator
recipes or arbitrary thresholds. Do not weaken execution safeguards or encourage
confidence inflation. If the evidence does not justify a change, return the
current prompt unchanged and an empty improvements list.

Return valid JSON only:
{
  "analysis": {
    "strengths": ["Supported strengths"],
    "weaknesses": ["Supported weaknesses and uncertainty"],
    "patterns": ["Patterns with their sample and regime limitations"]
  },
  "improvements": [
    {
      "area": "entry/exit/confidence/risk/other",
      "change": "One concise change",
      "rationale": "Evidence, failure condition, and how to test on unseen data"
    }
  ],
  "improved_prompt": "Complete prompt, unchanged if no revision is justified"
}
