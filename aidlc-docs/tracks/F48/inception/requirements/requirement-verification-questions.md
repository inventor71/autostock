# F48 사이드바 정리 — 요구사항 확인 질문

## Question 1
"Greeting 탭"이라고 언급하셨는데, 코드에서 "Greeting"이라는 이름의 탭을 찾을 수 없었습니다. 어떤 화면을 말씀하시는 건가요?

A) 사이드바 하단의 "Getting started" 박스 (무료 모델 안내, "Connect provider" 버튼이 있는 영역)
B) 웹 앱(packages/app)에 있는 탭
C) OpenCode TUI의 홈 화면에 표시되는 환영/팁 메시지
D) 기타 (아래 [Answer]: 태그 뒤에 설명해주세요)

[Answer]: 사이드바 상단에 세션 hash (e.g. ses_1727e25a...)를 띄워주는 탭이 있음

## Question 2
Context 탭을 "주식에 집중할 수 있게 한줄로" 바꾸라고 하셨습니다. 현재는 tokens, % used, $ spent 세 줄로 표시됩니다. 한 줄에는 어떤 정보를 보여주는 게 좋을까요?

A) 토큰 사용량만 간단히 (예: "12,345 tokens")
B) 토큰 + 비용 (예: "12.3k tokens · $0.42 spent")
C) 아예 Context 섹션 자체를 제거 (트레이딩 콘솔에서 컨텍스트 정보 불필요)
D) 기타 (아래 [Answer]: 태그 뒤에 설명해주세요)

[Answer]:  D. 토큰 + 비용 + used % 모두 한줄
