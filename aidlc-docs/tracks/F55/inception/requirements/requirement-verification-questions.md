## 의도 분석 요약 (현재 코드 상태)
- 타임라인 바(`timeline-bar.tsx` + `timeline-layout.ts`)는 `MarketRule`의 **4개 경계값**
  (`pre_open` 04:00 / `regular_open` 09:30 / `regular_close` 16:00 / `after_close` 20:00, 미 동부시간)에서
  파생된 **3개 구간 밴드**만 그립니다: **PRE**(프리마켓, 흐린 파랑) / **OPEN**(정규장, 초록) / **AFT**(애프터마켓, 보라).
- F45부터 24시간을 **12시간 윈도우 2개**로 타일링합니다. 정규장 중심 윈도우에는 PRE/OPEN/AFT가 보이지만,
  그 반대편 12시간(대략 20:00 ET → 다음날 04:00 ET)에는 **밴드가 전혀 그려지지 않습니다(빈 구간)**.
- 코드/설정/타입 어디에도 "데이마켓"·"day market"·"overnight" 세션 개념은 **없습니다**. 따라서 "데이마켓"이
  정확히 무엇을 가리키는지 먼저 확정해야 구현 범위가 정해집니다.

   (US/KR 멀티브로커 맥락 — 관련 트랙 F30/F33)
D) **기존 4개 경계 사이의 누락된 한 구간** — 위가 아니라, 단순히 4개 경계 중 라벨/밴드가 안 그려지는
   특정 시간대(예: 자정~프리마켓)를 메우고 싶다.
X) 기타 (아래 [Answer]: 뒤에 정확한 시간대/거래소/세션명을 적어주세요)
