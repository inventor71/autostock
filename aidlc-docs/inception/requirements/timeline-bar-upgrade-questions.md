## Q1. 시간대 표시 기준

현재 타임라인은 US Eastern(9:30-16:00) 기준이고, 턴 마커는 daemon이 실행되는 머신의 로컬 시간으로 표시됩니다.
한국에서 미장을 거래할 때 타임라인의 시간 표시 기준은 어떻게 할까요?

A) **마켓 현지 시간 (US Eastern)** — 거래소 시간에 맞춰 모든 걸 표시. 23:30 익일 06:00 한국 시간대와 무관
B) **사용자 로컬 시간 (한국 시간)** — 내 시간대 기준으로 변환해 표시. 9:30 ET → 23:30 KST
C) **듀얼 표시** — 마켓 현지 시간을 메인으로, 괄호 안에 로컬 시간 병기 (예: 10:30(00:30 KST))
D) **24시간 슬라이더 무국적** — 시간대 개념 없이 timeline을 24시간 슬라이더로만 표시, 마켓 오픈/클로즈만 마크

[Answer]: B

## Q2. Pre-market / After-hours 표시

미장은 정규장(9:30-16:00) 외에도 pre-market(4:00-9:30)과 after-hours(16:00-20:00)가 있습니다.
타임라인에서 이 구간들을 어떻게 처리할까요?

A) **정규장만 강조** — pre/after는 일반 배경과 동일하게. 정규장 구간만 배경색 변경
B) **세 구간 모두 구분** — pre-market, 정규장, after-hours 각각 다른 배경색/밝기로 표시
C) **정규장만 보여주기** — 24시간 말고 정규장 시간대만 타임라인에 표시 (확장 가능한 토글)
D) **Pre/after는 어두운 음영** — 정규장은 밝게, pre/after는 어둡게 처리해서 시간대 인식 도움

[Answer]:  B

## Q3. 날짜 네비게이션 방식

이전/다음 날짜로 이동하고 오늘로 돌아오는 UI는 어떻게 할까요?

A) **키보드 단축키** — `←` `→` 로 날짜 이동, `T`로 Today. 마우스 불필요
B) **마우스 클릭 버튼** — `<` `Today` `>` 텍스트 버튼을 타임라인 바 안에 배치. 클릭으로 조작
C) **키보드 + 마우스 모두 지원** — 단축키와 클릭 버튼 둘 다 제공
D) **채팅 명령어** — `/timeline 2026-05-30` 같은 slash command로 날짜 이동. UI 버튼 없음

[Answer]: C. D도 지원.

## Q4. 히스토리 보관 기간

이전 날짜 턴 히스토리를 얼마나 오래 보관하고 조회할 수 있어야 할까요?

A) **최근 5거래일** — 실용적인 단기 리뷰 범위
B) **최근 20거래일 (≈1달)** — 월간 리뷰 가능

## Q5. Human intervention 마커 표시 범위

Human steering 명령 중 어떤 것들을 타임라인 마커로 표시할까요?

A) **거래만** — human buy/sell/flatten/cancel 주문만 마커로 표시
B) **거래 + 생명주기** — A + pause/resume/halt-entries/kill 같은 daemon 제어 명령까지 포함

D) **거래 + 생명주기 + note** — C에서 approve/reject/unlock 같은 세부 승인은 제외 (노이즈)

## Q6. 마커 밀집 처리

15분 intraday + wake가 쌓이면 마커가 좁은 공간에 몰릴 수 있습니다. 어떻게 처리할까요?

A) **개별 표시** — 겹쳐도 각 마커를 개별 문자로 표시 (현재 방식)
B) **중첩 카운트** — 같은 x좌표에 여러 턴이 몰리면 `●+3` 같이 개수를 표시하고 클릭 시 확장
C) **세로 확장** — 타임라인 높이를 2줄로 늘려서 공간 부족 시 두 번째 줄에 마커 배치
D) **확대/축소** — 밀집 구간만 시간 단위로 줌인할 수 있는 인터랙션 제공

[Answer]: A

## Q7. 키보드 편의 기능

타임라인 바에 있으면 좋을 키보드 단축키가 있을까요?

A) **날짜 이동만** — `←` `→` `T` (Q3에서 선택한 방식)
B) **날짜 이동 + 마커 점프** — `←` `→` `T` + `[` `]` 로 이전/다음 마커로 포커스 이동
C) **전체 네비게이션** — B + 턴 타입별 필터 토글 (research/intraday/wake/human on/off)
D) **최소한으로** — 키보드 없이 마우스만으로 충분

[Answer]: A

## Q8. 주말/공휴일 처리

거래량이 없는 주말이나 공휴일의 타임라인은 어떻게 보여줄까요?

A) **빈 타임라인** — 마커 없는 24시간 바를 그대로 표시. "No trading activity" 정도만 표시
B) **건너뛰기** — 주말/공휴일은 날짜 네비게이션에서 자동으로 건너뛰고 가장 가까운 거래일로 이동
C) **회색 처리** — 타임라인을 흐리게(회색) 표시하고 "Weekend / Holiday" 라벨 추가
D) **캘린더 기반** — Alpaca API의 market calendar를 조회해서 거래일만 활성화, 비거래일은 비활성

[Answer]: A

## Q9. 24시간 뷰 마켓 시간 표시

24시간 전체를 보여줄 때 현재 시간과 마켓 상태를 어떻게 강조할까요?

A) **마켓 오픈/클로즈 경계선** — market open/close 시각에 세로 경계선(`│`) 또는 색상 변경
B) **마켓 구간 배경색** — market hours 전체 구간에 배경색. 나머지는 기본 배경
C) **경계선 + 배경색** — A와 B를 모두 적용. 가장 시각적으로 명확
D) **상단 라벨** — 타임라인 위에 "Pre-market / Market Open / After-hours" 라벨을 텍스트로 표시

[Answer]: A
